# C Fundamentals

C programs written while completing C programming course, as part of my roadmap toward becoming an AI/ML Engineer.

## Structure

### 01_PRACTICE
Independent practice problems, organized by topic:

**Loops & Arrays**
- Reverse an array
- Find duplicates
- Second largest element
- Print primes (1-100)
- Pattern printing (triangle)

**Functions**
- Prime check
- Factorial (recursion)
- GCD (Euclidean algorithm)
- Fibonacci sequence
- Pass-by-value vs pass-by-reference comparison

**Pointers**
- Swap using pointers
- Print array using pointer arithmetic
- Modify variable through pointer
- Sum array using pointer traversal

**Structs**
- Single student record
- Array of student structs
- Find highest marks
- Pass struct to function

### 02_#PROJECTS
Small complete programs:
- **calculator.c** — basic arithmetic calculator using switch-case
- **project_Guessing_Game.c** — number guessing game with randomization

## Why C first?

C builds real pointer and memory intuition, overlaps with my Sem 2 coursework, and is expected background for DSA and embedded/microcontroller work later in my degree.
